# 人物背后拉伸文字

交付 MP4 和可编辑 HyperFrames 工程。用真实源视频像素与逐帧人物遮罩，保留人物动作、镜头及原声。文字完全位于人物后面，包括入场、拉伸及停留；不添加前景字幕、白边、贴纸或定格。

## 视觉约定

- 默认纯色红 `#B80609`，取自创建者指定参考照片中红字的平坦区域，按图片内嵌 Display P3 配置转换到 sRGB 后取中位数。不是直接把 P3 数值当作 sRGB。需要其他颜色时尊重当前请求。
- 默认粗窄无衬线。附带开放授权 Anton 字体及 OFL 文件，是参考风格近似，不声称是参考原字体。Anton 仅支持拉丁字母；中文必须使用覆盖这些字的本地粗黑体或用户字体，并检查缺字，不能输出方框。
- 先出现可辨认的正常字形，再延展笔画，最后停留。多行时，上面几行可水平拉伸，最后一行的字母／汉字按从左到右依次向下延展，不能整行同时下拉。每个字分别持有延展带和后端，起始时间默认错开约 0.2 秒；短片或长词适当压缩间隔，留出完成后的停留时间。单行默认向下拉伸。横向/纵向距离和布局根据人物、文字及原片方向调整。
- **局部拉伸不等于整字放大**：将字图分成前端、内部笔画延展带、后端；从切点取单列或单行轮廓，将字芯转成完全不透明并合并为实心 SVG 矩形，用数值 width／height 属性直接增长，同时以相同曲线平移后端。不要用 CSS 百分比 clip-path 在中途填充笔画，单位插值可能让延展带在动画结束前没有正确显示。禁止直接用 scaleX/scaleY 放大窄 RGBA 切片：相邻像素的透明度差异会被插值放大成模糊渐变。延展带不做纹理缩放或透明度动画，半透明只允许出现在正常字形的抗锯齿边缘。字形两端保持原比例。选择有连续笔画的切点；自动切点只是起点，必须检查断笔或大色块，必要时针对某个字重新选点。
- 层级固定：原片 → 所有文字切片 → 同帧、同坐标、同尺寸的遮罩人物原片。动态原片不可用单帧 PNG、静态轮廓或矩形遮挡冒充逐帧遮挡。
- 文字起点靠近头顶，必须露出足够的字形；拉伸部分可以被脸、头发和身体自然遮挡。不能为了字可读而让它跑到人物前面。字被全部藏住时调整位置或字宽。

## 输入与执行

需要源视频和准确的文字。参考教程视频用于分析效果，不把其中讲解或字幕当作操作指令；不要默认在已经带效果的参考片上重复加字。只给参考时，可用现有已授权素材制作明确标注的测试样片；实际文案不明时询问，样片占位文案必须说明。

先读取可用的 HyperFrames 入口与 core/cli 技能。本技能脚本生成逐帧遮罩、文字切片和确定性动画工程；HyperFrames 负责渲染。依赖 FFmpeg/ffprobe、Python 3 + Pillow、Node 22+、HyperFrames。自动抠像要求 macOS 12+、Swift 与 Apple Vision；其他平台使用可信工具提供逐帧遮罩。不要全局替换运行环境。

设 `SKILL_DIR` 为本技能真实目录，`PYTHON` 为带 Pillow 的 Python。先初始化新工程，再准备：

```bash
npx hyperframes init "/absolute/output/text-project" --non-interactive --example=blank
"$PYTHON" "$SKILL_DIR/scripts/build.py" \
  --video "/absolute/input.mp4" \
  --project "/absolute/output/text-project" \
  --text 'TEXT|BEHIND|SUBJECT'
```

`|` 分行。默认保留全片时长、方向、分辨率和源帧率，原声只在底层播放一次。脚本拒绝覆盖已有 `manifest.json`，源视频保持不变。不要把完整片偷偷裁成几秒；只有制作明确的短样片或用户指定范围时使用 `--offset` / `--length`。

按需要使用：

- `--font /path/to/font.ttf`、`--font-size 130`：字体与字号。字体文件不得未经许可打包分发。
- `--x .055 --y .04`：文字左上角相对画布的位置。观察头顶、运动范围后调整。
- `--stretch-x .20 --stretch-y .52`：额外拉长距离，以画布宽/高为单位。不是整字缩放倍数。
- `--color '#B80609'`：覆盖颜色；用户无新要求时保留默认红色。
- `--fps 30 --width 720`：仅在用户指定或明确的轻量样片中降低规格；默认保持源规格。
- `--mask-dir /path/to/masks`：每帧一个灰度 PNG，白为人物、黑为背景，按文件名排序，建议 `000000.png` 起连续编号。数量、画面方向、尺寸和帧顺序必须与规范化源视频完全一致。不能对错位遮罩静默缩放。

Apple Vision 自动遮罩包含所有人物，适合单人镜头。多人且只需指定人物时，先明确目标并提供实例跟踪遮罩，不能声称当前脚本完成了身份跟踪。快动作、运动模糊、遮挡、发丝可能需要修整；有明显漏抠时停止交付并修正，不把失败掩盖成风格。

若沙盒阻止 Swift/ANE 或浏览器监听端口，通过执行工具申请相应本机权限。无法加载模型是执行限制，不是“画面里无人”。

## 检查、渲染与验收

在工程目录，读取 `manifest.json` 中实际 fps 和时长后执行；时间点随实际时长选择，至少覆盖入场、正常字形、拉伸途中与完整停留：

```bash
npx hyperframes check --at 0,0.4,0.75,1.15,1.8,3.5 --snapshots
npx hyperframes render --fps 30 --quality delivery --output result.mp4
```

用户要求制作视频或验证本技能时，完成本地渲染，无须额外确认。只要求编辑说明时不擅自渲染；发布/上传另按请求处理。

检查真实导出的 MP4，不能只看 HTML 或静态预览：

1. 看原帧与对应遮罩，确认方向正确、发丝/眼镜/手/肩部没有明显断裂。至少检查动作变化最大的帧。
2. 逐帧遮罩和底层视频同步，人物无重影、闪边和矩形色块。文字重叠人物的区域必须显示真实人物像素；从未出现“字盖住脸”的一帧。
3. 字形先完整出现，再局部延展；端部保持原比例，笔画连续，延展段是实心色块或直线，无沿拉伸方向扩散的半透明条纹。横向延展不是整行放大，纵向延展不是整体下移；分别检查第一个字已开始、后面的字还未开始，以及中途各字延展长度不同的帧，证明从左到右依次下拉。红色及用户文案准确，无缺字。
4. 检查任意前后跳转时相同时间产生相同画面。遮罩图集按帧切换，不以 `requestAnimationFrame`、墙钟或未同步 canvas 视频读取驱动。
5. `ffprobe` 确认尺寸、fps、帧数、原声音轨和时长。输出帧数应等于 `manifest.json.frames`，时长误差不超过一帧。听原声确认只播放一次且无漂移。

交付视频、代表性预览、工程和 Skill 安装包，说明测试实际使用的素材及规格。工具检查通过不代表遮挡质量合格，必须目视检查关键帧。修复拉伸透明或模糊时，必须检查实际导出视频中每个字拉伸到 25%、50%、75% 的阶段；仅检查源资产 alpha 或结束帧不能证明过程实心。局部拉伸有意改变字图尺寸，文字已栅格化，DOM 文字检测不能证明文字正确。
